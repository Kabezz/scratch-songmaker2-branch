## A fork of the scratch-editor repo which restores the song-maker2 directory.
https://kabezz.github.io/scratch-songmaker2-branch/scratch-gui/
### This is purely for historical purposes. I am not affiliated by the Scratch Team / Foundation for this restoration.

This is not intended to be a request to bring the directory back, rather just a full restoration of the directory, since the archive on the Wayback Machine is missing most of the instruments.

Please do not nag Scratch Team about the song-maker2 repo, or the existence of this fork.
